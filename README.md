# Бот «Карта дня» для канала

Каждый день в 10:25 по Москве публикует карту дня: 78 карт в случайном порядке, без повторов, пока колода не закончится. Ещё публикует посты из `queue.json` в указанное время.

## Запуск (один раз, ~5 минут)

1. В Telegram откройте @BotFather → `/newbot` → придумайте имя → получите токен.
2. Канал → Управление каналом → Администраторы → добавьте своего бота с правом «Публикация сообщений».
3. В этой папке скопируйте `.env.example` в `.env` и впишите токен и @username канала. Файл `.env` никому не отправляйте и не публикуйте.
4. Проверка (ничего не публикует):
   ```
   python bot.py check
   ```
   Должно быть написано «Права на публикацию: есть».
5. Запуск: двойной клик по `run_bot.bat`. Окно должно оставаться открытым.

## Важно

- Бот работает, пока включён компьютер и открыто окно. Если в 10:25 компьютер выключен, пост уйдёт при включении (до 12:25). Если позже, день пропускается.
- Чтобы работало круглосуточно без вашего компьютера, нужен недорогой VPS (~150–300₽/мес). Скрипт переносится туда без изменений.

## Полезные команды

- `python bot.py preview 5` — посмотреть следующие 5 карт дня
- `python bot.py queue` — что стоит в очереди и что уже вышло
- `python bot.py card-now` — опубликовать карту дня сейчас

## Как добавить пост в очередь

В `queue.json` допишите блок (время по Москве):
```json
{"at": "2026-12-01 18:20", "text": "Текст поста"}
```
Можно добавить картинку: `"image": "images/post1.jpg"`.

## Картинки к картам дня (по желанию)

Положите в папку `images` файлы с названием карты: `images/Звезда.jpg`, `images/Туз Кубков.png` и т.д. Если картинка есть, бот отправит её вместе с текстом.
